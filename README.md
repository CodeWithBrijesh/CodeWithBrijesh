I am a **Data Engineer / Azure Data Engineer** with solid practical experience building, operating, and modernizing high-throughput data pipelines and relational database systems.

* **Enterprise Foundation:** Proven corporate experience designing, maintaining, and troubleshooting high-volume, mission-critical batch and real-time data pipelines, handling tens of millions of records annually with zero data loss.

* **Data Modeling & Storage:** Deep expertise in Kimball dimensional modeling (Star/Snowflake schemas), Slowly Changing Dimensions (SCD Type 1 & 2), and ACID Delta Lake operations (`MERGE INTO`, Time Travel, file compaction).

## 💡 Core Engineering Capabilities

### 1. Cloud Lakehouse Architecture (Medallion Pattern)
* **Bronze (Raw Ingestion):** Scalable landing zone ingestion supporting batch CSV/JSON and schema validation with metadata watermarking.
* **Silver (Cleansed & Enriched):** Data deduplication, automated anomaly detection, quarantine split for bad records, and SCD Type 2 state tracking using PySpark and Delta Lake.
* **Gold (Business Aggregations):** Kimball-standard Star Schemas (`fact_` and `dim_` tables) optimized for low-latency BI queries and downstream reporting.

### 2. High-Performance ETL & Orchestration
* Metadata-driven pipelines dynamically querying control tables for scalable parallel orchestration.
* Event-driven triggers via Azure Event Grid with strict concurrency limits and backpressure regulation.
* Fail-fast fault tolerance: Multi-tier timeout guardrails, dead-letter quarantine queues, and automated orphan run cleanup.

### 3. Distributed PySpark & SQL Optimization
* Query performance tuning: Broadcast joins, partition pruning, Z-ORDER clustering, and shuffle partition management.
* Advanced SQL: Window functions (`ROW_NUMBER`, `DENSE_RANK`), Common Table Expressions (CTEs), dynamic T-SQL stored procedures, and index maintenance.

### 4. FinOps & Operational Excellence
* Serverless-first architecture preventing idle cloud compute expenses ($0 idle compute cost).
* Comprehensive audit logging, execution telemetry, and pipeline health monitoring.
